# 第二阶段：xG、历史红牌与确认首发更新层

**已完成数据接入、候选实现和对照，但没有证据支持替换现有预测器。网站和生产模型未改动。**

## 1. 数据真正补到了什么

- 德甲两个赛季370场逐场xG，与ESPN逐场比赛记录按日期、已核对的双方球队映射、主客顺序和进失球核对；没有模糊名称强行拼接。全部370场下载完成，正常化无异常。
- 370场均有双方实际首发与事件记录；经事件与球员红牌统计交叉核对，56场发生场上罚下。只有25场满足本轮红牌前xG分段的完整性与时长门槛，其他情况明确保留不可分段状态。
- 出场分钟从首发、换人和罚下事件重建。输出为正常比赛时钟下的90分钟暴露，不冒充含全部补时的精确实际分钟。替补席罚下不算场上少打一人；第二黄牌罚下与直接红牌分开记录。
- Understat逐射门和球员xG与ESPN球员按同场同队的规范化全名匹配；重名、名字不一致或个人进球统计冲突不拼接、不填零。ESPN门将缩写G与GK均按门将处理。
- 下载曾有14次失败，已在有限重试后补齐；最终没有下载缺口。原始响应、抓取时间和哈希保留在本地研究包。

## 2. 按你的四步实际做了什么

|步骤|实现|限制与决定|
|---|---|---|
|xG增强|同一组自身比赛，比较0%、25%、50%、100%实际进失球与xG融合|没有把xG当作必然优于进球；沿用早期开发期选比例|
|历史红牌|比较整场权重1、0.5、0.25；另比较红牌前xG按有效正常时钟暴露换算|分段至少30分钟，丢弃罚下所在分钟的模糊射门；没有合格分段就保留自身进失球分支而非编造11对11xG|
|确认首发层|单独保存名单、球员ID、位置、来源哈希、抓取时间和确认状态；确认且早于开球才可进入更新器|仅有11个starter标记不算官方确认；模型系数未通过前向验证时保存新名单但不改概率|
|两端验证|分别评价0–1球、5+、6+的Brier、AP、概率分箱、每日前五/前20%及日期分块bootstrap|固定开发/测试时间；历史实际首发实验明确为事后名单回放，不能当成真实前向发布|

## 3. 新的对照结果

红牌+xG分支开发期有88个共同目标，10月有24个共同目标。开发期选中50%xG融合＋历史红牌场权重0.25，没有选中红牌前片段换算。

|10月共同24场|原版Brier↓|候选Brier↓|结论|
|---|---:|---:|---|
|0–1球|0.212733|0.222832|变差|
|5球以上|0.198246|0.196224|改善|
|6球以上|0.129595|0.131451|变差|

综合目标从0.200658变为0.204149（越低越好）。候选减原版的日期分块95%区间为[-0.004287, 0.008780]。没有稳定胜出的证据，不切换生产模型。

首发贡献实验只有22个开发目标、3个10月对照，未达到预设的50个开发目标门槛。没有选择首发影响系数。不能用3场的胜负决定一个球员缺阵值多少进球。

## 4. 首发贡献候选没有偷偷用本场赛后表现

候选只使用本场首发球员身份；每名球员的xG/分钟与预计首发分钟来自目标日期至少两天前、该队自身比赛。预计分钟取个人此前首发分钟中位数。本场实际分钟、本场xG、本场进球不进入本场预测。
当前首发强度与上一次首发强度均按同一组个人历史计算，再比较25%、50%融合；不是给“少一个前锋”统一减0.3球。至少9名外场首发须各有180分钟个人记录，否则该场阵容分支留空。门将变化只作单独标记，未假造防守影响系数。
历史名单的首次抓取均晚于原开球时间，因此这25场最多是实际首发条件下的事后回放；即使评分好，也不能直接提升为前向模型。

## 5. 今晚实际首发采集状态

保存6个德甲目标的当前名单响应：5个采集时已开赛，只能归档；1个仍等待可验证确认。后一场响应没有双方完整首发，未补造预计名单。没有把今晚已发生的进球或红牌反灌回赛前概率。

## 7. 检查与复现

6组对抗性检查通过：红牌分钟边界与暴露、替补席罚下、缺失事件不当零、xG源冲突、首发来源与时间门槛、改变目标实际分钟/xG不影响首发强度。确认名单且存在已验证系数时的更新路径也检查了概率归一与独立输入标记。
```powershell
python collect_context.py
python retry_context.py
python normalize_context.py
python test_phase2.py
python phase2_experiment.py
python phase2_report.py
```
先前数据路径在脚本中指向本研究工作区；便携研究包包含同一相对目录布局。所有10月成绩仍是已查看过的数据上的回顾性比较，不是新盲测。

## 8. 下一步应收集什么

优先补齐更多球员的同源个人分钟与xG历史，减少首发特征因新援、样本不足和严格姓名匹配造成的留空；保留身份映射核对记录。然后持续保存真正开球前的确认首发快照及之后的90分钟结果，按预先固定的口径检验。不能通过降低样本门槛或换测试集来制造一次升级。
